Everything together-docker compose logs -f  or  docker compose logs --tail 50

Useful variations:
docker compose logs --since 15m middleware                 # only the last 15 minutes
docker compose logs -f middleware call-control             # two services side by side
docker compose logs --tail 500 middleware | grep -i error  # only errors
docker compose logs --since 30m livekit | grep -E "starting RTC session|candidate pair|removing participant"   # video calls joining or failing
docker compose ps                                          # is everything up?
docker compose logs --since 1h middleware | grep <requestId>

Incase something goes wrong
docker compose logs --since 1h middleware call-control | grep -E "ERROR|WARN"
docker compose logs --since 1h web | grep -E '" [45][0-9]{2} '
